# Summer Analytics 2026 — Projects

Projects completed as part of the **Summer Analytics 2026 Program**, organized by the **Consulting & Analytics Club, IIT Guwahati**.

This repository contains my two major projects completed during the program:

## 📂 Projects

### 1. Capstone Project — Age Group Prediction

A Machine Learning classification project focused on predicting age groups using health and demographic survey data.

**Model:** CatBoost Classifier
**Evaluation Metric:** Weighted F1 Score
**Validation F1 Score:** 0.7783

[View Capstone Project →](./Capstone-Project)

---

### 2. Week 2 Hackathon — Customer Conversion Prediction

A Machine Learning classification project focused on predicting whether a user would convert based on demographic, behavioral, browsing, and campaign-related features.

The project involved exploratory data analysis, missing-value handling, feature engineering, categorical encoding, model comparison, and final prediction generation.

**Models explored:** Random Forest, CatBoost
**Best recorded validation F1:** 0.3828

[View Week 2 Hackathon →](./Week-2-Hackathon)
